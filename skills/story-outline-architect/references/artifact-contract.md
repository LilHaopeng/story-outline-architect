# 大纲产物契约

创建、扩写或修订大纲时读取。本契约让人类可读的 Markdown 同时具备清晰层级、可追踪 ID 和自动化校验能力。

如何从体验、人物关系与阶段目标生成情节见 [story-generation.md](story-generation.md)。新增体验与戏眼字段用于新建项目与工作稿增强；既有项目可沿用原结构，历史锁定快照保持不变。

## 1. 权威来源与兼容原则

- 用户原稿、已确认设定、锁定版本优先于模型推断。
- `设定/` 保存世界与人物的稳定事实；`大纲/` 保存剧情规划；`追踪/` 保存随剧情推进变化的状态与故事义务；`正文/` 保存已发生事实。各司其职，避免多处重复维护同一事实。
- 预先提供世界观时，优先读取 `设定/世界观/15_大纲接口.md`；`大纲/世界观引用.md` 固定来源、版本与本书选用项，`追踪/世界状态变化.md` 记录尚未并入正典的拟议后果。
- `交付/*_小说大纲_*.docx` 是指定大纲版本与完成范围的排版阅读快照，`大纲/` 和 `追踪/` 下的 Markdown 仍为日常编辑的权威源文件。
- 兼容既有 `story-long-write` 项目的 `大纲/大纲.md`、`卷纲_第X卷.md`、`细纲_第XXX章.md`、`追踪/伏笔.md`、`时间线.md`、`角色状态.md`。
- 发现设定或前后文冲突时，建立问题条目并标注来源供确认；待定但不阻断当前层的信息标记为 `[待确认]`。

## 3. ID 与引用规则

| 对象 | 格式 | 示例 |
|---|---|---|
| 故事弧 | `ARC-NNN` | `ARC-003` |
| 剧情段 | `SEQ-NNN` | `SEQ-014` |
| 关键事件 | `EVT-NNN` | `EVT-042` |
| 章节 | `CH-NNN` | `CH-027` |
| 场景 | `CH-NNN-SC-NN` | `CH-027-SC-02` |
| 伏笔 | `F-NNN` | `F-008` |
| 反转 | `T-NNN` | `T-003` |
| 未闭环故事义务 | `LOOP-NNN` | `LOOP-012` |
| 状态检查点 | `S-NNN` | `S-006` |
| 变更请求 | `CR-NNN` | `CR-004` |
| 世界硬规则（外部引用） | `RULE-NNN` | `RULE-002` |
| 世界制度/势力（外部引用） | `INST-NNN` / `FAC-NNN` | `INST-001` / `FAC-002` |
| 世界结构冲突（外部引用） | `CON-NNN` | `CON-005` |
| 世界剧情种子（外部引用） | `SEED-NNN` | `SEED-011` |
| 世界状态（外部引用） | `WS-NNN` | `WS-003` |
| 世界地域/人物锚点（外部引用） | `REG-NNN` / `CHAR-NNN` | `REG-001` / `CHAR-002` |
| 世界规则漏洞（大纲侧引用别名） | `WLOOP-NNN`，核对源世界观 `LOOP-NNN` | `WLOOP-001` |

- ID 一旦进入锁定版本保持稳定；废弃对象标记 `retired`，不重复占用旧编号。
- L3 引用所属 ARC；L4 引用所属 ARC 与 SEQ；L5 引用所属章节。
- `requires` 指向更早建立的事件、状态、规则或信息；`causes` 指向已登记的后继对象。

### 世界观对象定义与引用的机器契约

大纲侧世界漏洞统一引用 `WLOOP-NNN`；源世界观仍定义 `LOOP-NNN`，不改动世界观原始 ID。裸 `LOOP-NNN` 在大纲里只表示未闭环故事义务。世界观选择记录与 `读取世界观`、`世界观引用`、`选用规则漏洞` 等结构化世界观字段中不得使用裸 `LOOP`；不要把来源文件说明当作替代别名的办法。其他位置的裸 `LOOP` 按故事义务理解，脚本不自动判断自由叙述的语义。

校验器从项目内 `设定/世界观/` 的当前 Markdown 来源登记以下三种定义，忽略围栏代码示例、HTML 注释和普通正文里的顺带提及：

```markdown
### RULE-001 标题定义
- REG-001：列表定义项
| CHAR-001 | 表格首列定义 |
```

标题支持 1–6 级；列表项须以 ID 开始并跟冒号；表格首列须是 ID，可用行内代码或加粗包裹。采用这些位置即声明对象；普通引用写在正文、字段值或表格其他列，避免让引用清单冒充定义。历史 `版本/`、`备份/`、`backup/`、`backups/` 和隐藏目录不进入当前定义表。登记定义只证明对象存在，不代替对象内容、正典状态或世界逻辑的审查。

世界观 ID 检查覆盖当前 `scope` 的《世界观引用》、Story DNA、架构、ARC、SEQ、Chapter；chapter 范围同时检查现有场景蓝图。越过 scope 的后续层不参与；同范围缺失定义、找不到本地来源的引用在 `--strict` 下报错，草案模式告警。外部或自定义目录的来源须先建立本项目内的明确来源映射，不能把未核验的引用当作有效。

## 5. L0：Story DNA 模板

```markdown
# Story DNA

- 状态：draft
- 项目名：
- 创作初衷：最初想写的具体处境、关系或感受及其原因
- 期待场面：代表性体验锚点；标明用户已确认或模型候选
```

**展开版等价写法**：三组分别满足以下任意一种写法，即满足该组结构要求；合并字段或拆分字段须非空。具体因果是否成立仍由语义审计判断。

| 精简版（默认） | 展开版（按需） |
|---|---|
| `阻碍与冲突` | `阻碍` 与 `冲突` |
| `决策与代价` | `决策` 与 `代价` |
| `后果与状态变化` | `后果` 与 `状态变化` |

旧的拆分版章纲继续有效，历史快照不迁移。`本章戏眼` 纯可选，缺少或留空均不产生校验警告；不要求每章都有金句，也不预先固定对白与感官装饰。推进脉络只选一种写法，条数按本章实际需要决定，避免复述上方字段。
