# 从核心体验生成情节

用于 `create / expand / repair` 的体验与戏剧张力设计，也用于 `audit` 中复核相应范围。先确定本次层级与主导驱动力，再选择所需方法；`compact` 项目可直接在现有文件中用短段落记录。

内容导航：体验锚点（L0）｜人物决策与群像化学反应（L1–L2）｜按驱动力组织主辅线（L1–L3）｜开篇试读窗口｜关键高潮反推（L2–L3）｜回报与人物高光（L2–L4）｜卷目标与可累积循环（L2–L3）｜落入现有字段。

## 1. 体验锚点与核心追读问题（L0）

先从用户原话、素材或已确认内容提取三件事：

- **创作初衷**：最初想写的处境、关系或感受。保留具体原因，如“一个总替别人收场的人，终于选择离开”。
- **期待场面**：最能体现该初衷的一个代表性瞬间，以及它为何动人。用户尚未给出时，可提供 1–2 个候选供确认。
- **核心追读问题**：读者愿意持续翻页等待答案的问题，如“他们能否在利益冲突中重建信任”“主角能否在旧制度崩解前保住航队”。

将核心故事凝练到约 100 字：人物处于什么开篇状态，什么事件打破原状，他追求什么，什么持续阻止他。

区分三者的分工：**梗概**说明故事走向，**追读问题**组织读者期待，**主题**通过不同选择与代价探索价值。后续节点可以推进、复杂化或重释核心问题；上层修订后对照体验锚点，确保核心创作乐趣不因结构细化而流失。

## 2. 人物决策依据与群像化学反应（L1–L2）

### 2.1 单人决策链条

先引用已有角色设定（已有世界观的出身、制度和职业规则由其来源拥有）。对主要人物建立以下行动推导链：

`关键经历 → 形成的信念 → 惯用应对 → 当前处境中的收益与冲突 → 有代价的选择`

按需明确人物最珍惜什么、最渴望获得什么、最怕失去什么、底线在哪里，以及受压时的沟通或行动习惯。人物标签用具体行为、适用情境和例外来落地；若有参考人物，只提炼其行为机制（如化解冲突的策略、表达情感的方式），结合本项目的经历重新生发。

例如：曾长期独自解决困难 → 相信求助会给别人添麻烦 → 遇事提前隐瞒并独自扛下 → 导致搭档缺少关键信息而误判局势 → 被迫在“维持独立形象”与“交出部分控制权请求协助”之间做出选择。

### 2.2 核心人物关系张力与镜像对照（Cast Chemistry & Foil）

人物弧光在关系碰撞中最容易显影。在 L1 架构或人物决策依据中，用简明的一两句话核对主要人物之间的化学反应：

- **联系与相互影响**：这些人因何产生联系，在目标、手段、利益、责任或认知上有哪些互补与分歧？相同信念也可以因处境或承担成本不同而产生张力。说明关系如何改变彼此的行动，不要求所有关系绑定合作或信念互斥。
- **镜像与对照（Foil，按需）**：当相似处境下的不同选择能增加本书意义时，再设置镜像。对手与配角有自己的利益和底线，不必人人配一组镜像。
- **认知错位（按需）**：若存在合理误读，说明它的证据和消解条件；也可通过准确理解后的分歧、共同实践或支持推进关系，不强制制造误会。

## 3. 按驱动力组织主辅线（L1–L3）

选择一项主导驱动力，必要时搭配次要驱动力，汇入五轨总表协同推进：

| 驱动力 | 读者主要等待的变化 | 外部事件承担的作用 |
|---|---|---|
| **关系** | 信任、理解、吸引、承诺、边界如何变化 | 迫使人物相互看见、作出选择，并改变之后的相处模式 |
| **成长** | 能力、认知、身份、自主权或责任如何变化 | 提供挑战、实践、反馈与可保留的阶段成果 |
| **解谜** | 真相是什么，如何得到可信答案并承受代价 | 建立证据链、解释竞争与带来连锁后果的发现 |
| **求生** | 如何摆脱具体威胁，在极限下能保住什么 | 改变威胁形态、可用资源、逃生方案与艰难取舍 |
| **事业** | 能否完成事业/建设目标，以何种路径与代价达成 | 改变资源配置、组织协作、竞争格局与制度责任 |

关系驱动（含爱情、友情、亲情、师徒、宿敌）围绕共同事件重点追问：
1. 外部目标与阻碍是什么，双方为什么发生联系或选择共同参与？
2. 哪些互补、支持或真实分歧使关系发生变化？
3. 各自怎样行动，对方从中看见或误读了什么？
4. 事件结束后哪一项关系状态（信任度、话语权、边界约定）发生了实质改变，下一次互动有何不同？

## 4. 开篇试读窗口设计

先根据体量、章节长度、叙事形式和类型承诺划定窗口，并记录涵盖哪些 CH/SEQ 或预计字数。3–5 章是参考尺度；序章、冷开场和多视角作品可跨剧情段安排，不固定为 `SEQ-001`。只展开本次已经规划的范围。

窗口内检查以下任务，顺序与组合按作品调整：

1. **人物与切入吸引力**：用有辨识度的处境、行动、关系或观察方式建立关注与共情，不按固定动作数计数，也不要求主角立刻讨喜。
2. **规则/卖点最小可见化**：通过与本书体验有关的具体困境、实践或互动，让读者看见核心机制；背景说明的详略服务理解与阅读节奏。
3. **首次体验验证**：给出一条值得推理的悬疑线索、一次独特互动、可信的专业表现或局部破局，让读者初步确认本书承诺。它不必是获胜、强反转或解决危机。
4. **持续阅读理由**：检查窗口结束时哪些人物处境、关系、问题或可能性值得继续关注；不强制每次以更大的危机收尾。将这些理由接入后续已规划的节点。

窗口是编辑检查范围，不是统一录取线；资料尚停留在 L0–L2 时只评估设计意图，不能声称已验证具体章节的留存效果。

## 5. 先定关键高潮，再反推积累（L2–L3）

只为本次范围内的重要节点展开高潮设计（远期保留锚点即可）：

```markdown
### 关键节点：名称 / 现有 ARC、SEQ 或 EVT ID

- 要回应的期待：读者在等待、担心或相信什么
- 前置积累：哪些不同事件逐步建立这一期待，各自增加什么新筹码或新认知
- 触发：什么行动、证据或突发结果让积累发生质变
- 关键选择：谁在什么不可兼得的选项间选择，依据与代价是什么
- 回报与人物高光：本次兑现什么体验；主角或关键角色如何通过行动展现高光
- 后续变化：关系、认知、能力、资源或局势怎样改变，由谁在后文读取
```

先从高潮后的目标状态向前反推：“人物做出这个选择需要先具备什么认知、能力与契机？读者要产生强烈共鸣需要先亲眼看到什么？”再按时间顺序正向复核因果与信息差，合并只在原地重复受挫的冗余铺垫。高潮的力量来自认知翻转与不可逆的选择（一次平静的决裂、公开承认秘密或放弃旧执念同样可以成为强高潮）。

## 6. 回报与人物高光（L2–L4）

设计阶段回报时区分：**此前期待 → 本次已兑现或通过具体情节重释的内容 → 后续变化**。仍未兑现但决定延期的承诺单独登记新窗口与理由；延期可能增加期待，但不算已兑现或已重释，不能用于抬高回报覆盖率。

人物高光优先结合角色的核心特质或专业能力，在有退路或有诱惑的高压处境下通过主动选择呈现：

`特质/能力依据 → 高压两难处境 → 决定与行动 → 承担的风险或代价 → 对他人与后续局势的实质影响`

对手同样按其目标、资源与底线行动，靠智商在线的博弈烘托高光，避免靠配角强行降智来凑爽点。

## 7. 卷目标、阶段成果与可累积循环（L2–L3）

从终局反推当前卷/Arc 的阶段目标，用精炼段落交代：
- **起点与完成条件**：起始处境、阶段目标及可观察的成败标准。
- **破局路径与瓶颈**：需要调动什么能力、资源或同盟，最大的卡点在哪里。
- **阶段结算与保留成果**：哪些收益、能力、关系或代价被永久保留下来（即使阶段任务失败，也应保留关键情报、教训或新关系，避免“一键归零”）。
- **新局面与承接**：阶段成果如何改变主角的议价权或责任，又如何引出下一卷的新压力。
