# 从核心体验生成情节

用于 create / expand / repair 的体验设计，也用于 audit 中检查相应范围。先确定本次层级与主导驱动力，再选择所需方法；compact 项目可直接在现有文件中用短段落记录。

内容导航：体验锚点；人物决策；主辅线与关系；高潮倒推；回报与高光；卷目标与循环；生成后的复核。

## 1. 体验锚点与核心追读问题（L0）

先从用户原话、素材或已确认内容提取三件事：

- 创作初衷：最初想写的处境、关系或感受。保留具体原因，如“一个总替别人收场的人，终于选择离开”。
- 期待场面：最能体现该初衷的一个瞬间，以及它为何动人。用户尚未给出时，提供少量候选并标明来源与待确认状态；它不自动成为正典或锁定剧情。
- 核心追读问题：读者愿意持续等待答案的问题，如“他们能否重新建立信任”“主角能否获得决定自己生活的能力”。

将核心故事压缩到约 100 字：人物处于什么开篇状态，什么事件打破原状，他追求什么，什么持续阻止他。字数用于聚焦，不作机器门槛。

梗概、追读问题与主题各有作用：梗概说明故事走向，追读问题组织期待，主题通过不同选择与代价探索价值。关系能否复合是悬念；怎样的改变足以重建信任可以成为主题。

后续节点可以推进、复杂化、重释核心问题，也可以为其建立必要条件；不要求每章都简单地“更近/更远”。上层修订后对照体验锚点，说明哪些情节仍提供该体验。若用户主动改变初衷，记录变化及下游影响。

## 2. 用人物决策依据生成情节（L1-L2）

先引用已有角色设定。缺少关键依据时，仅提出本故事需要的候选，区分确认事实与推测；已有世界观的出身、制度和职业规则继续由其来源拥有。

对主要人物建立以下链条：

`关键经历 → 形成的信念 → 惯用应对 → 当前处境中的收益与冲突 → 有代价的选择`

在既有角色来源或架构的人物决策依据中，按需补充：最珍惜什么、最想获得什么、最怕失去什么、底线是什么，以及受压时通常如何沟通或行动。背景能影响信念，同样的背景仍允许不同选择；不以出身、职业或家庭类型直接断定人格。

标签用于抓住初始印象，再用具体行为、适用情境和例外说明它。若使用 1–2 个参考人物，记录借鉴的机制，如处理冲突的策略、表达感情的方式；重新建立本项目的经历和动机，避免照搬标志性经历、桥段或台词。没有参考时无需补找。

基础信息只保留能影响行动、认知、关系或辨识度的部分。外貌与物件可参与互动和回收，是否使用取决于作品调性。

例如：曾长期独自解决困难 → 相信求助会给别人添麻烦 → 提前隐瞒并承担 → 合作伙伴缺少必要信息而无法参与 → 必须选择继续保护自我形象，还是交出部分控制并请求帮助。候选经历须与已有材料核对。

## 3. 按驱动力组织主辅线（L1-L3）

选择一项主导驱动力，必要时搭配次要驱动力。五轨仍用于观察同一故事，不因新增驱动力额外维护一套竞争总纲。

| 驱动力 | 主要等待的变化 | 外部事件需要提供的作用 |
|---|---|---|
| 关系 | 信任、理解、吸引、承诺、边界等如何变化 | 使人物相互看见、作出选择，并改变之后的相处 |
| 成长 | 能力、身份、自主权或责任如何变化 | 提供挑战、实践、反馈与可保留的成果 |
| 解谜 | 什么是真相，如何得到可信答案 | 建立证据、解释竞争与有后果的发现 |
| 求生 | 如何摆脱具体威胁，能保住什么 | 改变威胁、资源、可用方案与取舍 |
| 事业 | 能否完成事业目标，以何种方式和代价 | 改变资源配置、协作、竞争、责任与成果 |

混合型明确主次及交汇点；职业、冒险等情节若本身就是核心承诺，应保留相应内容。外部细节的详略由它对本书体验、因果与可信度的贡献决定。

关系驱动时，按实际关系挑选少数状态维度，写清双方的感受和行动依据；友情、亲情、师徒和对手关系同样适用。围绕一段共同任务问：

1. 外部目标与阻碍是什么，双方为什么参加？
2. 什么使他们相互靠近或需要合作，什么真实分歧又使他们疏离？
3. 各自怎样行动，对方因此看见或误读了什么？
4. 哪一项关系状态改变，下一次互动将怎样不同？

相互吸引与分歧可以同时存在。争吵或亲密接触之后，若认知、边界和行动方式完全复位，应检查是否只在重复情节。

示例：共同完成项目 → 她看见他愿意承担失败责任，同时发现他习惯替她决定 → 信任增加而自主权冲突显现 → 下一次合作必须先约定决策边界。双方都保留能动性。

“谁离不开谁”只是一种关系转折。双向信任、平等协作、选择分开等均可成为高潮后的状态；解决原先冲突需要相应的改变与行动依据。

## 4. 先定关键高潮，再反推积累（L2-L3）

只为本次范围内的重要节点展开；远期保留锚点，近期再补细节。一个高潮卡可以是短段落，也可使用以下字段：

```markdown
### 关键节点：名称 / 现有 ARC、SEQ 或 EVT ID

- 要回应的期待：读者在等待、担心或相信什么
- 前置积累：哪些不同事件逐步建立这一期待，各自增加什么
- 触发：什么行动、证据或结果让积累发生质变
- 关键选择：谁在什么选项间选择，依据与代价是什么
- 回报与人物高光：本次回应什么；高光按需填写
- 后续变化：关系、认知、能力、资源或局势怎样改变，由谁在后文读取
```

从预期的高潮后状态向前追问：人物作此选择需要什么认识、能力与机会；读者理解其分量需要先见到什么；每个积累节点为何让下一步成立。再按时间顺序复核人物当时的知识、欲望、行动机会与因果，剔除为了场面方便才出现的行为。

积累可建立信任、形成习惯、增加承诺、暴露分歧、改变解释或关闭选项。相同委屈/危险反复加码而没有新的意义、应对或成本时，合并或重构。张力可以松紧交替，也可以通过甜蜜、日常协作或能力实践积累。

揭示若重释旧事，应提前存在可回看的证据和合理视角；选择继续使用既有信息与反转台账记录，不另造同类台账。区分作者真相、读者认知和人物认知。

高潮强度来自此前积累的回应与状态变化。平静的拒绝、公开承认错误或放弃一个目标都可成为高潮，不必升级事故规模。触发事件本身之后，还要看人物如何选择以及留下什么后果。

## 5. 回报与人物高光（L2-L4）

设计回报时说明：此前承诺/期待是什么，本次如何兑现、部分兑现、延期或重释，之后留下什么变化。尚未到期的期待继续按窗口追踪；长期压抑要有适合类型的阶段回应。

根据本书承诺选择回报：能力验证、获得尊重、被理解、特殊对待、自主选择、成功合作、反击、解谜或有意义的告别。无需每章都包含显性爽点，也无需统一采用“受压后打脸”的 U 型。

涉及对手的回报，从其具体目标、资源、利益与先前行动推导得失；被主角否定的角色仍有自己的行为逻辑。避免把羞辱工具人当成所有类型的默认回报。

人物高光优先选择能代表人物的一个特质或专业能力，在真实压力下通过行动呈现：

`特质/能力依据 → 有其他选择的高压处境 → 决定与行动 → 风险或代价 → 对他人与后续局势的影响`

高光可以体现坚持、成长、专业判断或对自身盲点的修正。人物因关系改变原则时，铺垫价值排序为何变化及后果；违背原则、失去判断或依赖对方并不自动证明爱。专业高光受世界/现实规则和人物已具备的能力约束。

将高光安排在合适节点，可与高潮或阶段回报重合；没有独立作用时无需另插一场展示。检查经历与能力依据，避免为了突出一人而让其他人突然失能。

## 6. 卷目标、阶段成果与可累积循环（L2-L3）

从终局反推当前可行动的阶段目标。卷是出版/阅读组织单位，Arc 是状态变化单位；按项目映射，允许一卷包含多个 Arc 或一条 Arc 跨卷，不额外强加层级。

卷纲或 Arc 的阶段成果说明可用一段话覆盖：

- 起始处境、本阶段目标和可观察的完成条件。
- 需要什么行动、能力、资源或合作，主要瓶颈是什么。
- 实际计划结果：成功、部分成功或失败；哪些收益、经验与损失被保留。
- 新结果解锁什么行动，带来什么责任、风险或新压力，下一阶段为何开始。
- 预计字数/章节窗口，以及不能破坏的世界规则和能力约束。

篇幅与资源预算用于发现支撑不足或节奏失衡，可据实际推进调整；它们不创造无来源的世界上限。失败可以连接下一阶段，只要下一阶段读取真实后果。

规划循环时把当前成果带入下一轮：

`局部需要 → 采取行动 → 得到反馈/成果 → 使用并保留部分成果 → 获得新的行动条件与压力`

例如从依靠体力谋生，到掌握稳定技艺，再到经营协作关系；每一轮改变收益结构、解决问题的方式或承担的责任。物质、能力、地位、关系和自主权都可以作为成果，但按本书目标选择。

收益也可以被夺走或耗尽，但说明原因，并检查是否仍保留知识、能力、关系、选项或有意义的损失。若连续循环恢复到原点、只换更大数字，应改瓶颈、策略或局势；不能靠反复归零维持篇幅。

## 7. 落入现有字段并复核

| 记录位置 | 使用方法 |
|---|---|
| L0 | 保存初衷、期待场面、核心故事、追读问题与主导驱动力 |
| L1 | 引用人物决策依据，安排主辅线交汇及关键节点概览 |
| Arc / 卷纲 | 写关键高潮与前置积累、阶段成果及下一阶段承接 |
| Sequence | 将所选关键节点拆成必要的积累、触发、选择和回报 |
| Chapter | 用新信息、状态变化、目标情绪、爽点/情绪回报等既有字段说明本章作用 |
| 既有台账 | 继续记录实际启用的状态、因果、伏笔、信息与未闭环；用现有 ID 回指 |

交付前按 [audit-rubric.md](audit-rubric.md) 做语义检查。自动脚本只能检查结构、字段与引用；字段齐全、情绪分值或高光数量都不能证明可读性与感染力。按当前范围给具体节点证据和未覆盖部分。
